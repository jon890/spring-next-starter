# rule-5: 추적 파일에 비밀값, 개인 정보, 운영 값을 두지 않는다

## 까닭

공개 저장소에 한 번 push 한 값은 되돌릴 수 없다. 지워도 이력과 포크, 검색 캐시에 남는다.

## 지키는 방법

- 비밀값과 운영 주소는 환경 변수나 CI secret 으로 받는다. 코드에는 이름만 둔다.
- 예시 값은 `example.com`, `localhost` 처럼 예약된 값이나 로컬 전용 값을 쓴다.
- 감출 값을 예시로 문서에 적지 않는다. 무엇을 감추는지 설명하려고 적으면 그 값이 공개된다.

## 검사

`scripts/checks/check-public-safe.ts` 가 두 층으로 본다.

- 형태 패턴: 개인키, 알려진 토큰 모양, 주소 안의 계정과 비밀번호, 사설 IP, 예시 도메인이 아닌 메일 주소. 스크립트가 갖는다.
- 값 목록: 내 환경의 호스트 이름이나 계정처럼 모양으로 알 수 없는 값. 저장소 밖 파일에 두고 `PUBLIC_REPO_DENYLIST` 로 경로를 준다. CI 는 같은 이름의 repository secret 을 읽는다.

추적 파일의 지금 내용만 본다. 커밋 메시지와 앞 커밋에 넣었다 지운 값은 push 전에 직접 확인한다.

## 예외

`compose.yaml` 과 `application.yml` 의 로컬 DB 계정은 로컬 개발 전용 예시 값이라 허용한다. 운영 값은 환경 변수로 덮어쓴다.
